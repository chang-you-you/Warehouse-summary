# 📊 女装上货自动填数工具

一个基于 Flask 的 Web 工具，用于自动将上货数据填入 Excel 模板的对应位置。

## ✨ 功能特点

- 📍 支持多个地点（西柳、哈、郑州）
- 📅 支持多个月份和日期选择
- 👗 支持多种风格和品类联动选择
- 🔄 自动记忆上次选择（地点、月份、日期、风格）
- 📤 上传 Excel 模板，自动匹配并写入数据
- 📥 下载更新后的 Excel 文件
- 🔍 自动查找已有列，找不到则使用空列
